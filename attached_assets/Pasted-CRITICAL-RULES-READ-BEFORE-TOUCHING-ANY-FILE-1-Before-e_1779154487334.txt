- The <h1> → slides up + fades in, duration 500ms, 80ms delay
- The <p> heroSub → slides up + fades in, duration 500ms, 180ms delay

Use this pattern for each element (adjust delay with inline style):

      to   { opacity: 1; transform: translateY(0); }
    }
    .hero-fade-up { animation: heroFadeUp both; }
  `}</style>

Then apply className="hero-fade-up" + inline style animationDuration/Delay to each element.

Also add a slow shimmer/pulse to the gradient background itself — a subtle
animated shine that moves across the hero. Add this inside the outer blue div

    className="pointer-events-none absolute inset-0 opacity-20"
    style={{

      backgroundSize: "200% 100%",
      animation: "heroShimmer 3.5s ease-in-out infinite",

  />
  <style>{`

      0%   { background-position: 200% center; }
      100% { background-position: -200% center; }
    }
  `}</style>

Make the outer blue div position: relative (add "relative overflow-hidden" to its className)
so the shimmer stays inside.
