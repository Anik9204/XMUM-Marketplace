BUG 1 — DUPLICATE COMPILED .js FILES IN ADMIN APP
═══════════════════════════════════════════════
PROBLEM: Every file in artifacts/xmum-admin/src/ has a compiled .js
duplicate sitting next to the .tsx source file. For example:

      rm "$f"

BUG 3 — subscribeToNotifications IS MISSING FROM notifications.ts
═══════════════════════════════════════════════
PROBLEM: NotificationBell.tsx imports subscribeToNotifications from
"@/lib/notifications" but this function does not exist in
notifications.ts. The bell currently falls back to the old
getNotifications() getDocs call, meaning notifications are NOT
real-time — the bell only updates on page load.

FIX: In artifacts/xmum-market/src/lib/notifications.ts:
  1. Add onSnapshot to the firebase/firestore imports.
  2. Add this exported function at the bottom of the file:

  export function subscribeToNotifications(
    uid: string,
    callback: (notifs: AppNotification[]) => void
  ): () => void {
    const q = query(
      collection(db, "users", uid, "notifications"),
      orderBy("createdAt", "desc"),
      limit(20)
    );
    return onSnapshot(
      q,
      (snap) => {
        const notifs = snap.docs.map((d) => {
          const data = d.data();
          return {
            id: d.id,
            ...data,
            createdAt: toMillis(data.createdAt),
          } as AppNotification;
        });
        callback(notifs);
      },
      () => {} // silently ignore snapshot errors (offline, permissions)
    );
  }

  3. In NotificationBell.tsx, replace the current useEffect that
  calls getNotifications() with one that uses subscribeToNotifications:

  useEffect(() => {
    if (!user) return;
    setLoading(true);
    const unsub = subscribeToNotifications(user.uid, (notifs) => {
      setNotifications(prev => {
        const prevIds = new Set(prev.map(n => n.id));
        const brandNew = notifs.filter(n => !prevIds.has(n.id) && !n.read);
        brandNew.forEach(n => {
          if (Notification.permission === "granted") {
            try {
              new Notification(n.title, { body: n.body, icon: "/favicon.svg" });
            } catch {}
          }
        });
        return notifs;
      });
      setLoading(false);
    });
    return unsub;
  }, [user?.uid]);

  Remove the setLoading(true) that was before the old getDocs call.
