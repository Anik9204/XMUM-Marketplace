TASK: Step 10 — Upgrade firebase-functions SDK from v4.9.0 to v5

CONTEXT:
The functions package currently has "firebase-functions": "^4.0.0" in dependencies.
There are 3 exported functions in artifacts/functions/src/index.ts:
1. dailySubscriptionCheck — uses functions.region().pubsub.schedule().timeZone().onRun()  (v1 API)
2. dailySoldListingCleanup — uses functions.region().pubsub.schedule().timeZone().onRun()  (v1 API)
3. moderateContent — already uses onCall from "firebase-functions/v2/https"  (v2 API — no change needed)

firebase-functions v5 drops the v1 namespace (functions.pubsub, functions.https, etc).
The two scheduled functions must be migrated from v1 to v2 before upgrading the SDK.

STEP A — Migrate the two scheduled functions from v1 to v2 API (do this BEFORE installing v5)

In artifacts/functions/src/index.ts, make these surgical changes:

   import { onSchedule } from "firebase-functions/v2/scheduler";

2. Replace the dailySubscriptionCheck export. Change this:

     .region("asia-southeast1")
     .pubsub.schedule("0 8 * * *")
     .timeZone("Asia/Kuala_Lumpur")
     .onRun(async () => {
   To this:
   export const dailySubscriptionCheck = onSchedule(
     { schedule: "0 8 * * *", timeZone: "Asia/Kuala_Lumpur", region: "asia-southeast1" },
     async () => {
   And remove the closing `return null;` and replace it with just a closing `});`
   
   Specifically: the function body stays 100% identical. Only the wrapper changes.
   The old wrapper ends with `.onRun(async () => {` and closes with `return null;\n  });`
   The new wrapper ends with `async () => {` and closes with `});`
   The `return null;` line inside must be removed (onSchedule handlers return void, not null).

   Change from:

   To:
   export const dailySoldListingCleanup = onSchedule(
     { schedule: "0 3 * * *", timeZone: "Asia/Kuala_Lumpur", region: "asia-southeast1" },

   And remove its `return null;` line too.

4. The top-level import `import * as functions from "firebase-functions";` is now unused.
   Remove that line entirely.

5. moderateContent already uses v2 API (onCall from "firebase-functions/v2/https") — do NOT touch it at all.
