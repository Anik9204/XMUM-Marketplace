### Retention / Scalability notes (implement manually or as a Cloud Function):
 
Each document has an `expiresAt` field set to 30 days from creation. To auto-clean, create a Cloud Function in `artifacts/functions/src/index.ts` that runs on a schedule:
 
```ts
// Scheduled cleanup: delete platformActivityFeed documents older than 30 days
// Run daily using Cloud Scheduler (pubsub)
export const cleanActivityFeed = functions.pubsub
  .schedule("every 24 hours")
  .onRun(async () => {
    const cutoff = Date.now();
    const q = query(
      collection(db, "platformActivityFeed"),
      where("expiresAt", "<", cutoff),
      limit(500)
    );
    const snap = await getDocs(q);
    const batch = writeBatch(db);
    snap.docs.forEach((d) => batch.delete(d.ref));
    await batch.commit();
  });
```
 
This keeps the collection small and avoids unbounded growth. With ~30 events/day, 30-day retention = ~900 docs max — extremely cheap.
