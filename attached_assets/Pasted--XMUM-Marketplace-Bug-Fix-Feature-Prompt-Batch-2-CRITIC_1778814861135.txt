## ISSUE 1 — ListingCard shows user ID next to the location pin when no meetup spot is selected

Specifically, the broken code block looks like this (around line 316–327):

```tsx

  <span className="flex items-center gap-1 truncate">
    <MapPin size={10} />
    {listing.meetupSpot}
  </span>
) : (
  <span className="flex items-center gap-1">
    <MapPin size={10} />
    {listing.userEmail.split("@")[0]}    {/* ← THIS IS THE BUG */}
  </span>
)}
```

### What must happen

If `listing.meetupSpot` is empty or undefined, show **nothing at all** in that slot — not the user ID, not a pin icon, not any placeholder. The `<Clock>` timestamp on the right must stay exactly where it is.

### Files to read first

- `src/components/ListingCard.tsx` (full file)

### Implementation — surgical edit only

Find the exact `else` branch above and replace the entire ternary with:

```tsx

  <span className="flex items-center gap-1 truncate">
    <MapPin size={10} />
    {listing.meetupSpot}
  </span>

  <span /> 
)}
```

That is the **only change** in this file. Do not touch any other line.

## ISSUE 4 — Show last name (not user ID) in listing cards and home page greeting

### What is broken

**A — ListingCard** (`src/components/ListingCard.tsx`): The "by @{listing.userName}" line (around line 341) shows the email prefix (e.g., `@s12345`) because `listing.userName` is set to `user.email?.split("@")[0]` when a listing is created in `PostPage.tsx` (line 595).

**B — HomePage greeting** (`src/pages/HomePage.tsx`): The greeting says `Good day, {userProfile.displayName} 👋` (line 352), where `displayName` is the email prefix (set during sign-up in `auth.ts` line 40 as `email.split("@")[0]`).

**C — PostPage** (`src/pages/PostPage.tsx`): When creating a listing, `userName` is saved as the email prefix. It should instead be saved as the last name derived from `userProfile.fullName`.

### Helper function — define once, use everywhere

A "last name" extractor is needed in multiple places. Define this small pure function **at the top of each file that needs it** (do not create a new shared lib file for this — just inline it where needed):

```ts
function getLastName(fullName: string): string {
  const parts = fullName.trim().split(/\s+/);
  return parts[parts.length - 1] || fullName.trim();
}
```

Logic: split on whitespace, return the last word. If the user has only one word as their name, it returns that word. If `fullName` is empty, fall back to the raw value.
