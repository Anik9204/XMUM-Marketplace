=================================================================
STEP 5 — REPLIT PREVIEW NOT WORKING
=================================================================

Separately, for the Replit preview not showing the app:

Read .replit file and check the [[ports]] section.
It must have exactly ONE port mapping:

  [[ports]]
  localPort = 5000
  externalPort = 80

If there are TWO entries both mapped to externalPort = 80 
(e.g. both 5000→80 and 8081→80), delete the duplicate. 
Replit's proxy gets confused when two local ports both 
map to external port 80 and shows "app not running" in 
the preview pane even when the server is running.

Also confirm vite.config.ts server settings:
  server: {
    host: '0.0.0.0',
    port: 5000,
    strictPort: false,
    allowedHosts: 'all',
  }

After fixing .replit, click Stop then Run in Replit.
The preview pane should now load the app directly.
