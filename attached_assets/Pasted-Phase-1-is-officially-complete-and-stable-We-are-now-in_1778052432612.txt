Action 2: Firestore Pagination ("Load More")

The Issue: The home page currently fetches all active listings at once, which will drain Firebase reads as the app scales.

The Fix: Update the home page feed query to use limit(12).

The UX: Add a "Load More" button at the bottom of the feed. When clicked, use Firestore's startAfter(lastVisible) cursor to fetch the next 12 listings and append them to the UI. Hide the button if there are no more listings to fetch.

The Setup: Ensure Tailwind CSS is configured for class based dark mode (darkMode: 'class' in tailwind.config.js).

The Toggle: Add a Sun/Moon toggle icon in the top navigation bar.

The State: Use a library like next-themes (if compatible with Vite/React) or a custom useEffect to save the user's preference to localStorage and apply the dark class to the HTML root. Ensure the background and text colors invert cleanly.
