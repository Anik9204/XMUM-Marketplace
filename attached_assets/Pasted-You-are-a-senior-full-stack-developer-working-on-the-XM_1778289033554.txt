═══ FEATURE C: DAILY DIGEST NOTIFICATIONS ══════════════════════

In src/lib/types.ts, extend the AppNotification type union:

In src/lib/notifications.ts, add a new function:
  export async function sendDailyDigestIfDue(uid: string, listings: Listing[]): Promise<void>

  Logic:
    1. Check Firestore users/{uid} document for a field: lastDigestSentAt (number timestamp).
    2. If it does not exist or Date.now() - lastDigestSentAt >= 24 * 60 * 60 * 1000:
       a. Count total active listings.
       b. Sum total views across all listings: listings.reduce((sum, l) => sum + (l.viewCount ?? 0), 0). (viewCount will be added in the next step.)
       c. Get unread message count from getUserConversations (sum unreadCount[uid]).
       d. Construct a notification:
          - title: "Your daily marketplace summary"
          - body: "Your {N} listings received {V} views in the last 24h. You have {M} unread messages."
          - type: "daily_digest"
       e. Call addNotification(uid, ...) to write it to the user's notification subcollection.
       f. Update users/{uid} with { lastDigestSentAt: Date.now() } via updateDoc.
