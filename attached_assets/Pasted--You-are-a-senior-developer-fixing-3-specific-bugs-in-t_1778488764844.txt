### BUG FIX 1 — Back button on ShopPublicPage causes "Shop not found"

**The problem:** In `src/pages/ShopPublicPage.tsx`, the back button uses `navigate(-1 as any)`. In Wouter (this app's router), `-1` is not a valid navigation target — it doesn't trigger browser history back. Instead Wouter treats it as navigating to the route `"-1"` which doesn't exist, so the page re-renders and shows "Shop not found".

**The fix:** Replace the back button's onClick with `window.history.back()`:

Find this line in `ShopPublicPage.tsx`:
```tsx
<button onClick={() => navigate(-1 as any)} className="absolute top-3 left-3 bg-black/30 text-white p-2 rounded-full hover:bg-black/50 transition">
```

Replace with:
```tsx
<button onClick={() => window.history.back()} className="absolute top-3 left-3 bg-black/30 text-white p-2 rounded-full hover:bg-black/50 transition">
```

Also remove the `navigate` destructure from `useLocation` in `ShopPublicPage` if it is no longer used anywhere else in that file. Check first — if `navigate` is used elsewhere in the file, keep it. If it's only used for the back button, replace:
```tsx
const [, navigate] = useLocation();
```
with:
```tsx
const [location] = useLocation();
```
or remove it entirely.

### BUG FIX 2 — Banner and logo upload broken in Shop Settings

**The problem:** In `storage.rules`, the `shopBanners` rule is:
```
match /shopBanners/{userId}/{allPaths=**} {
  allow write: if request.auth != null
               && request.auth.uid == userId
```

But in `src/lib/shops.ts`, the upload path is:
```ts
const storageRef = ref(storage, `shopBanners/${shopId}/banner.jpg`);
```

The storage rule checks `request.auth.uid == userId` but the path uses `shopId` (the Firestore document ID of the shop), **not** the user's UID. These never match, so every banner upload is silently rejected by Firebase Storage.

**Fix Part A — Update `storage.rules`:**

Replace the `shopBanners` rule:
```
match /shopBanners/{shopId}/{allPaths=**} {
  allow read: if true;
  allow write: if request.auth != null
               && request.resource.size < 3 * 1024 * 1024
               && request.resource.contentType.matches('image/.*');
}
```

Replace the `shopLogos` rule:
```
match /shopLogos/{shopId}/{allPaths=**} {
  allow read: if true;
  allow write: if request.auth != null
               && request.resource.size < 2 * 1024 * 1024
               && request.resource.contentType.matches('image/.*');
}
```
