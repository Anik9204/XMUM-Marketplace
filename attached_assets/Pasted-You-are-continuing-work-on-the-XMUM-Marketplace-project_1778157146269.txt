## FEATURE 7 — Post auto-deletion after 30 days with reminders

### Architecture decision (IMPORTANT — read before coding)
Firebase Cloud Functions (server-side cron) are NOT available in this Replit/Firebase project without a paid Blaze plan and separate deployment. Therefore, auto-deletion must be implemented CLIENT-SIDE using a "lazy expiry" pattern: expiry is checked and enforced when the user visits their Profile page and when listings are loaded. This is a standard pattern for student/hobby apps.

The approach:
1. Each listing already has `createdAt` (timestamp in milliseconds).
2. Define EXPIRY_MS = 30 days in milliseconds = `30 * 24 * 60 * 60 * 1000`.
3. Define REMINDER_MS = 23 days in milliseconds = `23 * 24 * 60 * 60 * 1000` (7 days before expiry).
4. When `ProfilePage` loads the user's listings, check each one: if `Date.now() - listing.createdAt >= EXPIRY_MS`, call `deleteListing(listing)` automatically and remove it from the list.
5. Show a dismissible notification banner on ProfilePage if any listing is within the reminder window (23–30 days old).
6. Show a toast notification when a listing is auto-deleted.

### Step A — Add expiry constants to listings.ts
At the top of `listings.ts`, after the `PAGE_SIZE` constant:
```ts
export const LISTING_EXPIRY_MS = 30 * 24 * 60 * 60 * 1000; // 30 days
export const LISTING_REMINDER_MS = 23 * 24 * 60 * 60 * 1000; // 23 days (7-day warning)
```

### Step B — Update ProfilePage.tsx to auto-delete expired listings and show reminder
In `ProfilePage.tsx`, after `getUserListings` returns data, run the expiry check:

```ts
import { deleteListing, getUserListings, markAsSold, LISTING_EXPIRY_MS, LISTING_REMINDER_MS } from "@/lib/listings";

// After fetching listings:
const now = Date.now();
const expired = data.filter(l => now - l.createdAt >= LISTING_EXPIRY_MS && l.status === "active");
const active = data.filter(l => !(now - l.createdAt >= LISTING_EXPIRY_MS && l.status === "active"));

// Auto-delete expired listings silently in background
if (expired.length > 0) {
  Promise.allSettled(expired.map(l => deleteListing(l))).then(() => {
    if (expired.length === 1) {
      setSuccessToast(`"${expired[0].title}" has been automatically removed after 30 days.`);
    } else {
      setSuccessToast(`${expired.length} listings have been automatically removed after 30 days.`);
    }
  });
}

listingsCache.current = active;
setListings(active);

// Check for listings in the reminder window (23–30 days old)
const expiringSoon = active.filter(
  l => l.status === "active" && 
  now - l.createdAt >= LISTING_REMINDER_MS && 
  now - l.createdAt < LISTING_EXPIRY_MS
);
if (expiringSoon.length > 0) {
  setExpiryReminders(expiringSoon);
}
```

## FEATURE 8 — Notification system (in-app, client-side)

### Architecture decision (IMPORTANT — read before coding)
A full push notification system requires Firebase Cloud Messaging and a service worker, which is complex and overkill for a student app. Instead, implement an IN-APP notification bell that shows a dropdown of recent app events that happened during the current session, plus persistent notifications stored in Firestore under `users/{uid}/notifications` subcollection.

### What notifications are generated:
1. Listing auto-deleted (generated in ProfilePage when expiry check runs)
2. Listing marked as sold (generated in ProfilePage/ListingDetailPage when markAsSold is called)
3. Welcome notification (generated once when user first logs in — check Firestore if a welcome notification already exists)

### Step A — Add notification types to types.ts
```ts
export interface AppNotification {
  id: string;
  type: "listing_deleted" | "listing_sold" | "welcome";
  title: string;
  body: string;
  createdAt: number;
  read: boolean;
  listingId?: string;
}
```

### Step B — Create src/lib/notifications.ts
```ts
import { collection, addDoc, getDocs, updateDoc, doc, query, orderBy, limit, serverTimestamp } from "firebase/firestore";
import { db } from "./firebase";
import { AppNotification } from "./types";

function toMillis(val: unknown): number {
  if (typeof val === "number") return val;
  if (val && typeof (val as any).toMillis === "function") return (val as any).toMillis();
  return Date.now();
}

export async function addNotification(
  uid: string,
  data: Omit<AppNotification, "id" | "createdAt" | "read">
): Promise<void> {
  try {
    await addDoc(collection(db, "users", uid, "notifications"), {
      ...data,
      createdAt: serverTimestamp(),
      read: false,
    });
  } catch {
    // Notifications are non-critical — silently fail
  }
}

export async function getNotifications(uid: string): Promise<AppNotification[]> {
  try {
    const q = query(
      collection(db, "users", uid, "notifications"),
      orderBy("createdAt", "desc"),
      limit(20)
    );
    const snap = await getDocs(q);
    return snap.docs.map(d => {
      const data = d.data();
      return { id: d.id, ...data, createdAt: toMillis(data.createdAt) } as AppNotification;
    });
  } catch {
    return [];
  }
}

export async function markNotificationsRead(uid: string, ids: string[]): Promise<void> {
  try {
    await Promise.allSettled(
      ids.map(id => updateDoc(doc(db, "users", uid, "notifications", id), { read: true }))
    );
  } catch {
    // Silent
  }
}
```
