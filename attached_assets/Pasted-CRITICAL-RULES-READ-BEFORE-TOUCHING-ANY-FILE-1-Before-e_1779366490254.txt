TASK: Replace the localStorage-based daily post rate limit with a Firestore-based
active listing slot system. The new rule: a user may have at most 6 active listings
at any time. Deleting a listing frees a slot immediately. No time window — just slots.

WHY: The current checkRateLimit() uses localStorage which can be cleared by the user
(incognito, clearing storage) to bypass the limit. activeListingCount in Firestore
is already tracked correctly — it increments on create and decrements on delete.
Using it as the gate is simpler, server-authoritative, and gives users the
delete-to-free-a-slot behaviour they expect.
