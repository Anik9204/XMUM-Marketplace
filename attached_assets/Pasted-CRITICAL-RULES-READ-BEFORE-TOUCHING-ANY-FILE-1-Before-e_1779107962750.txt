      Currently ANY authenticated Firebase user (any email domain) can upload
      to shopBanners. It must be restricted to @xmu.edu.my addresses only,
      consistent with every other writable path in the rules.

Find this exact block:
    match /shopBanners/{shopId}/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null
