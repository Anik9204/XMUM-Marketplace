## PART 1 — CRASH FIX (Critical): "Can't find variable: Notification" on iOS Safari

File: artifacts/xmum-market/src/components/NotificationBell.tsx

The Web Notifications API (`Notification` global) does not exist on iOS Safari.
The current code accesses it unconditionally, causing a ReferenceError crash on iPhone.

Find this block (around lines 55–60):

    brandNew.forEach(n => {
      if (Notification.permission === "granted") {
        try {
          new Notification(n.title, { body: n.body, icon: "/favicon.svg" });
        } catch {}
      }
    });

Replace it with:

    brandNew.forEach(n => {
      if (typeof Notification !== "undefined" && Notification.permission === "granted") {
        try {
          new Notification(n.title, { body: n.body, icon: "/favicon.svg" });
        } catch {}
      }
    });

That is the ONLY change needed in this file. Do not touch anything else.

## PART 2 — PERFORMANCE FIX: Add vendor chunk splitting to Vite build

File: artifacts/xmum-market/vite.config.ts

This adds manual chunk splitting so Firebase, React, and UI libraries are
separated into their own cached chunks. Users only re-download what changed.

Find the `build` section:

  build: {
    outDir: path.resolve(import.meta.dirname, "dist"),
    emptyOutDir: true,
  },

Replace it with:

  build: {
    outDir: path.resolve(import.meta.dirname, "dist"),
    emptyOutDir: true,
    rollupOptions: {
      output: {
        manualChunks: {
          "vendor-react": ["react", "react-dom"],
          "vendor-firebase": [
            "firebase/app",
            "firebase/auth",
            "firebase/firestore",
            "firebase/storage",
          ],
          "vendor-ui": ["lucide-react", "wouter"],
        },
      },
    },
  },

Do not change anything else in vite.config.ts.

## PART 3 — PERFORMANCE FIX: Lazy-load images in ListingCard

File: artifacts/xmum-market/src/components/ListingCard.tsx

Find every <img> tag that renders a listing photo. There will be one or two
instances rendering the listing image (look for listing.photos[0] or similar).

For each <img> tag rendering a listing photo, add these two attributes if they
are not already present:
  loading="lazy"
  decoding="async"

Example — if you find:
  <img src={listing.photos[0]} alt={listing.title} className="..." />

Change it to:
  <img src={listing.photos[0]} alt={listing.title} className="..." loading="lazy" decoding="async" />

Only add these attributes to listing photo <img> tags. Do not touch any other
img tags (avatars, icons, etc.) and do not change any class names or other attributes.
