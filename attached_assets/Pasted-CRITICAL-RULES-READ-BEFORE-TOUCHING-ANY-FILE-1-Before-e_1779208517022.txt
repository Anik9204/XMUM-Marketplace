preserving line breaks and whitespace. The text is rendered in a plain <p> tag
with no whitespace-pre-wrap, so all newlines and intentional spacing written in
the editor are collapsed into one continuous block.

Additionally, the truncation logic splits bio by /\s+/ which destroys newlines —
the truncated preview should be based on character count, not word splitting,
so whitespace is preserved.

FIX — make ONLY these two surgical changes inside the ShopBio function:

1. Change the truncation logic from word-based to character-based:
   - Replace the three lines:
       const bioWords = bio.trim().split(/\s+/);
       const shouldTruncate = bioWords.length > 60;
       const displayBio = shouldTruncate && !bioExpanded
         ? bioWords.slice(0, 60).join(" ") + "…"
         : bio;
   - With:
       const TRUNCATE_CHARS = 300;
       const shouldTruncate = bio.trim().length > TRUNCATE_CHARS;

         ? bio.trim().slice(0, TRUNCATE_CHARS) + "…"
         : bio.trim();

   - Replace:
       <p>{displayBio}</p>

       <p className="whitespace-pre-wrap">{displayBio}</p>
