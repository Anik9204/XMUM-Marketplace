FIX 1 — File: artifacts/xmum-market/src/App.tsx

ROOT CAUSE: When Firebase redirects to www.xmummarket.com/__/auth/action after 
verifying email on their own page, there is no "mode" param in the URL. The 
current handler does "if (!mode) return" which causes the app to render the 
NotFound page because /__/auth/action has no wouter route.

Find this exact block inside FirebaseActionHandler:

    // No mode = normal navigation, do nothing
    if (!mode) return;

Replace it with:

    // If on /__/auth/action with no mode, Firebase already handled verification.
    // Redirect to homepage and open sign in modal.
    if (!mode) {
      if (window.location.pathname === "/__/auth/action") {
        navigate("/?signin=1", { replace: true });
      }
      return;
    }

That is the only change in this file.

---

FIX 2 — File: artifacts/xmum-market/src/components/Layout.tsx

ROOT CAUSE: The ?signin=1 param is read correctly and opens the AuthModal, but 
the param is never cleaned from the URL. If the user refreshes the page while 
the modal is open or after closing it, the modal opens again unexpectedly.

Find this exact block in Layout.tsx:

  useEffect(() => {
    const params = new URLSearchParams(window.location.search);
    if (params.get("signin") === "1") {
      setShowAuth(true);
    }
  }, []);

Replace it with:

  useEffect(() => {
    const params = new URLSearchParams(window.location.search);
    if (params.get("signin") === "1") {
      setShowAuth(true);
      // Clean the param from URL so refreshing doesn't re-open the modal
      window.history.replaceState({}, "", window.location.pathname);
    }
  }, []);

That is the only change in this file.
