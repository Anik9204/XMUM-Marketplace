- design.md (the Stitch output — read it fully)
- src/index.css
- src/components/Layout.tsx
- src/components/ListingCard.tsx
- src/components/AuthModal.tsx

  --shadow-card, --shadow-hover, --shadow-modal, --shadow-sheet,

Extend tailwind.config.js to expose all design tokens as Tailwind utility classes referencing the CSS variables, e.g. bg-brand, text-brand, rounded-card, shadow-card, etc.

Update the header, bottom nav, desktop nav, and footer in Layout.tsx to match the new design spec from design.md exactly — colors, heights, spacing, font sizes, icon sizes, active states.

─── STEP 4 — Apply to ListingCard.tsx ───────────────────────────

─── STEP 5 — Apply to AuthModal.tsx ─────────────────────────────

─── STEP 6 — Apply to HomePage.tsx ──────────────────────────────
Update the tab selector, category chips, skeleton loader, and empty state to match the new design.

─── CONSTRAINTS ─────────────────────────────────────────────────
- Do NOT change any logic, routing, or Firestore calls.
