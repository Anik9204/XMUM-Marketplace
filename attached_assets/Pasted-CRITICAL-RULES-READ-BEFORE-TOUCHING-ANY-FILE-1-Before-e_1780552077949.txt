FIX 1 — Keyboard gap (the ~60px dead space below the input when keyboard opens)

The outer wrapper div currently has this inline style:
  style={{ height: 'calc(100dvh - var(--header-h) - var(--verif-banner-h) - var(--bottom-nav-h))' }}

The problem: when the virtual keyboard opens on Android/iOS, the bottom nav is pushed off screen, but --bottom-nav-h (60px) is still subtracted from the height, creating a 60px dead gap below the input bar.

The fix:
1. Add a new state variable at the top of the component:
   const [keyboardOpen, setKeyboardOpen] = useState(false);

2. Add a useEffect that listens to visualViewport resize to detect keyboard open/close:
   useEffect(() => {
     const vv = window.visualViewport;
     if (!vv) return;
     const handler = () => {
       // If visual viewport height is less than 75% of window inner height, keyboard is open
       setKeyboardOpen(vv.height < window.innerHeight * 0.75);
     };
     vv.addEventListener('resize', handler);
     return () => vv.removeEventListener('resize', handler);
   }, []);

3. Change the outer wrapper div's inline style to:
   style={{
     height: keyboardOpen
       ? 'calc(100dvh - var(--header-h) - var(--verif-banner-h))'
       : 'calc(100dvh - var(--header-h) - var(--verif-banner-h) - var(--bottom-nav-h))',
   }}

   And change the md: Tailwind class on the same div from:
     md:[height:calc(100dvh_-_var(--header-h)_-_var(--verif-banner-h))]
   to:
     md:[height:calc(100dvh_-_var(--header-h)_-_var(--verif-banner-h))]
   (keep it unchanged — this is already correct for desktop)

FIX 2 — Messages don't scroll into view when keyboard opens

Currently, scrollIntoView is only triggered inside the subscribeToMessages callback when new messages arrive. When the keyboard opens and the viewport shrinks, the last message scrolls off the top.

The fix:
In the same visualViewport resize useEffect from Fix 1, add a scroll call after setKeyboardOpen:
   const handler = () => {
     const isOpen = vv.height < window.innerHeight * 0.75;
     setKeyboardOpen(isOpen);
     if (isOpen) {
       // Small delay to let layout reflow settle before scrolling
       setTimeout(() => {
         messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' });
       }, 80);
     }
   };
