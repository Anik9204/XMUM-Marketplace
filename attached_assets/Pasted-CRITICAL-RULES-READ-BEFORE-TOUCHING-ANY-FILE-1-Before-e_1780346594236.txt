TASK: Make ListingDetailPage update in real-time when a listing's status, title, price, description, photos, or isArchived changes — without requiring a page refresh.

FILE: artifacts/xmum-market/src/pages/ListingDetailPage.tsx

CURRENT BEHAVIOUR:
The listing is fetched once via getListing(params.id) inside a useEffect. After that, no live updates occur. If another user marks it sold, edits it, or an admin archives it, the current viewer does not see the change.

THE FIX:
Add a new import at the top of the file alongside the existing firebase imports:
  import { onSnapshot, doc as fsDoc } from "firebase/firestore";

Then add a NEW useEffect AFTER the existing useEffect that calls getListing. This new useEffect sets up an onSnapshot listener on the single listing document. It must:

1. Only run when params?.id is available and the initial loading is complete (loading === false) and listing is not null.
2. Watch doc(db, "listings", params.id).
3. On each snapshot, update only these fields in the listing state: status, title, price, description, photos, isArchived, isReportHeld. Do NOT update viewCount from the snapshot — leave viewCount updates to the existing local optimistic increment already in the file.
4. If the snapshot document does not exist (doc.exists() === false), set listing to null so the "listing not found" UI shows.
5. Return the unsub function for cleanup.

The new useEffect should look like this:

  useEffect(() => {
    if (!params?.id || loading || !listing) return;
    const unsub = onSnapshot(
      fsDoc(db, "listings", params.id),
      (snap) => {
        if (!snap.exists()) {
          setListing(null);
          return;
        }
        const data = snap.data();
        setListing((prev) =>
          prev
            ? {
                ...prev,
                status: data.status ?? prev.status,
                title: data.title ?? prev.title,
                price: data.price ?? prev.price,
                description: data.description ?? prev.description,
                photos: data.photos ?? prev.photos,
                isArchived: data.isArchived ?? prev.isArchived,
                isReportHeld: data.isReportHeld ?? prev.isReportHeld,
              }
            : prev
        );
      },
      () => {}
    );
    return () => unsub();
  }, [params?.id, loading]);

Do NOT modify the existing getListing useEffect. Do NOT modify the viewCount useEffect. Do NOT change any JSX or other logic.
