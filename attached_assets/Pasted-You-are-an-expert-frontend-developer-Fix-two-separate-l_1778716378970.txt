BUG 1 — Chat Header Overlaps Messages in MessagesPage.tsx
Root Cause (already identified)
In src/pages/MessagesPage.tsx, the outer wrapper div on line ~796 uses hard-coded calc() values to set its height:

    : "h-[calc(100dvh-136px)] sm:h-[calc(100dvh-144px)] md:h-[calc(100dvh-64px)]"

ElementMobile (default)Mobile sm:Desktop md:Top header (<header>)56px (h-14)56px56pxMobile bottom nav60px + env(safe-area-inset-bottom)60px0px (hidden)Verification banner (when shown)~40px~40px~40px
The current numbers leave extra or missing pixels, causing the chat header (the bar showing the other user's name/avatar inside the conversation pane) to visually overlap scrolled messages.
Fix Instructions
Replace the hard-coded height div with CSS custom properties so it automatically tracks the real header height. Apply all three of these changes:
Step 1 — Add a CSS custom property to src/index.css:

:root {
  --header-h: 56px;       /* matches h-14 on the <header> element */
  --bottom-nav-h: 60px;   /* matches min-h-[60px] on the mobile bottom nav */
  --verif-banner-h: 0px;  /* updated via JS when banner is visible */
}
Step 2 — In src/components/Layout.tsx, inject the banner height dynamically:
In the Layout component, find the verification banner render:
tsx{user && !user.emailVerified && <VerificationBanner />}
Wrap it so it sets the CSS variable when mounted:
tsx{user && !user.emailVerified && (
  <div ref={(el) => {
    document.documentElement.style.setProperty(
      '--verif-banner-h',
      el ? `${el.offsetHeight}px` : '0px'
    );
  }}>
    <VerificationBanner />
  </div>
)}
Also add a useEffect cleanup so the variable resets to 0px when the banner unmounts (i.e. when email gets verified).
Step 3 — Replace the buggy height div in MessagesPage.tsx:
tsx// REPLACE THIS:
<div className={`flex overflow-hidden overscroll-none ${
  !!user && !user.emailVerified
    ? "h-[calc(100dvh-184px)] sm:h-[calc(100dvh-192px)] md:h-[calc(100dvh-112px)]"

  style={{
    height: 'calc(100dvh - var(--header-h) - var(--verif-banner-h) - var(--bottom-nav-h))',
  }}

tsx<div
  className="flex overflow-hidden overscroll-none md:[height:calc(100dvh_-_var(--header-h)_-_var(--verif-banner-h))]"

  }}

This ensures:

Mobile: Total height = viewport minus header (56px) minus bottom nav (60px) minus optional verification banner.
Desktop: Total height = viewport minus header (56px) minus optional verification banner. No bottom nav deduction needed since md:hidden hides the nav.
Keyboard on mobile: Because we use 100dvh (dynamic viewport height), the layout automatically shrinks when the software keyboard appears, so the input box is never buried.
No more overlap: The chat header inside the conversation panel is part of a flex-col where the messages area has flex-1 overflow-y-auto min-h-0. Since the outer container now has the exact correct height, the messages scroll area fills the remaining space precisely, and the chat header (user name bar) stays pinned at the top of the pane without overlapping any messages.
