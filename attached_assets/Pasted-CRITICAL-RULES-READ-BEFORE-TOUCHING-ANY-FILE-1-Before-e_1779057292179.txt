PROBLEM 1 — FIX: Subscription Config Save Fails
═══════════════════════════════════════════

FILE: src/pages/SubscriptionConfigPage.tsx

The form currently throws "Missing or insufficient permissions" when saving.

The cause: The Firestore security rule for appConfig only allows writes 
from users with role "admin". The page does not check the user's role 
before attempting to save — it just fails silently at the Firestore write.

FIX — Do TWO things:

1. At the top of the SubscriptionConfigPage component, import and use 
   the useAuth hook:
   
   const { isAdmin } = useAuth();

2. Before rendering the form, check if isAdmin is false. If the user 
   is NOT an admin, do not show the form at all. Instead render a 
   locked state UI:
   - A lock icon
   - Heading: "Admin Access Required"
   - Message: "Only admins can modify subscription settings. 
     Contact the system administrator."
   - This prevents editors from seeing a form they cannot submit.

3. If the user IS an admin, render the form as normal.

Do not change the form fields or the save logic — only add this role guard.

PROBLEM 3 — MISSING: Automated Subscription Lifecycle (Cloud Function)
═══════════════════════════════════════════

This is the most important missing piece. Right now, shops NEVER 
automatically expire or get hidden even when their subscription date 
passes. Nothing watches the clock. We need a Firebase Cloud Function 
that runs automatically every day.

LOCATION: Create this in the Firebase Functions folder. If a functions 
folder does not exist yet, create it properly with package.json, 
tsconfig.json, and src/index.ts using Firebase Admin SDK and 
firebase-functions v2.

CREATE a scheduled Cloud Function called "dailySubscriptionCheck" 
that runs every day at 8:00 AM Malaysia time (Asia/Kuala_Lumpur).

The function must do the following steps IN ORDER:

STEP 1 — Read config
  Read the document appConfig/subscriptions from Firestore.
  Extract: subscriptionDays, graceDays, reminderDays (default 7 if missing).

STEP 2 — Get all approved shops
  Query the "shops" collection where approvalStatus == "approved".
  These are the only shops that have active subscriptions.

STEP 3 — For each shop, check its subscription state:

  Get the shop's subscriptionExpiresAt (Firestore Timestamp).
  Get the current time.

  Calculate:
    - isExpired = subscriptionExpiresAt < now
    - isInGrace = subscriptionExpiresAt < now AND 
                  subscriptionExpiresAt + (graceDays * 86400000ms) > now
    - isPastGrace = subscriptionExpiresAt + (graceDays * 86400000ms) < now
    - daysUntilExpiry = (subscriptionExpiresAt - now) / 86400000
    - needsReminder = daysUntilExpiry <= reminderDays 
                      AND daysUntilExpiry > 0 
                      AND shop.reminderSentAt == null

  Then take the appropriate action:

  IF isPastGrace:
    - Update shop: { subscriptionStatus: "expired", isActive: false }
    - Do NOT send any more notifications (already sent during grace)

  ELSE IF isInGrace AND shop.subscriptionStatus != "grace":
    - Update shop: { subscriptionStatus: "grace", isActive: false }
    - Send notification to shop owner (see notification format below)
      Title: "⚠️ Your shop has been hidden"
      Body: "Your subscription for [shopName] has expired. 
             Your shop is now hidden from the marketplace. 
             You have [X] days remaining to contact the admin 
             and renew your subscription before your data is removed."
    - Send notification to ALL admin users (query users where role == "admin")
      Title: "🔔 Shop Subscription Expired: [shopName]"
      Body: "The shop [shopName] owned by [ownerEmail] has expired 
             and entered the grace period. Please follow up with 
             the owner for renewal."

  ELSE IF needsReminder:
    - Update shop: { reminderSentAt: now }
    - Send notification to shop owner:
      Title: "⏰ Your subscription expires in [X] days"
      Body: "Your shop [shopName] subscription will expire on [date]. 
             Please contact the admin to renew your subscription 
             before your shop is hidden from the marketplace."
    - Send notification to ALL admin users:
      Title: "🔔 Renewal Reminder: [shopName]"
      Body: "The shop [shopName] subscription expires in [X] days 
             on [date]. Owner: [ownerEmail]. Please follow up."

NOTIFICATION FORMAT:
Write notifications to Firestore at:
  users/{userId}/notifications/{auto-id}
  
Each notification document should contain:
  {
    title: string,
    body: string,
    type: "subscription_expired" | "subscription_reminder" | "subscription_grace",
    shopId: string,
    shopName: string,
    createdAt: Firestore Timestamp,
    isRead: false
  }

To find the admin users to notify: query the "users" collection 
where role == "admin" and send a notification to each one found.

STEP 4 — Log a summary
  After processing all shops, log:
  "Daily subscription check complete. 
   Processed: X shops. 
   Expired: X. 
   In grace: X. 
   Reminders sent: X."

ERROR HANDLING:
  Wrap the entire function in a try/catch.
  If a single shop fails to update, log the error and continue 
  processing the remaining shops — do not crash the entire function.
