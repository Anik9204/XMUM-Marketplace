FIX 4 — Layout.tsx shop pending count poll does not restart when user's shop list changes
File: artifacts/xmum-market/src/components/Layout.tsx

Find the useEffect that polls getPendingActivityCount. It will look like:
  useEffect(() => {
    if (!user) { setShopPendingCount(0); return; }
    let interval: ReturnType<typeof setInterval>;
    getProfile(user.uid).then((profile) => {
      const shopId = profile?.myShopIds?.[0];
      if (!shopId) return;
      getPendingActivityCount(shopId).then(setShopPendingCount).catch(() => {});
      interval = setInterval(() => {
        getPendingActivityCount(shopId).then(setShopPendingCount).catch(() => {});
      }, 60000);
    }).catch(() => {});
    return () => clearInterval(interval);
  }, [user?.uid]);

The issue is `interval` is declared inside the `.then()` so if `getProfile` rejects, `interval` is never assigned and `clearInterval(undefined)` is a no-op — which is fine. But there is a separate issue: `interval` is declared with `let` inside the effect, but the cleanup closure captures it by reference correctly in JS. This is actually safe as-is for the declared bug.

The real fix needed: move the `let interval` declaration outside the `.then()` so the cleanup always has a valid reference even if the promise resolves late:

  useEffect(() => {
    if (!user) { setShopPendingCount(0); return; }
    let interval: ReturnType<typeof setInterval> | undefined;
    getProfile(user.uid).then((profile) => {
      const shopId = profile?.myShopIds?.[0];
      if (!shopId) return;
      getPendingActivityCount(shopId).then(setShopPendingCount).catch(() => {});
      interval = setInterval(() => {
        getPendingActivityCount(shopId).then(setShopPendingCount).catch(() => {});
      }, 60000);
    }).catch(() => {});
    return () => { if (interval) clearInterval(interval); };
  }, [user?.uid]);

Only the `let interval` declaration position and the cleanup guard change. Nothing else.

Add a mounted guard:

    if (tab !== "saved" || !user) return;
    let mounted = true;
    setSavedLoading(true);
    getSavedListings(user.uid)
      .then(async (saved) => {
        if (!mounted) return;
        setSavedCount(saved.length);
        const results = await Promise.all(saved.map(s => getListing(s.listingId).catch(() => null)));
        if (!mounted) return;
        setSavedListings(results.filter((l): l is Listing => l !== null));

      .catch(() => {})
      .finally(() => { if (mounted) setSavedLoading(false); });
    return () => { mounted = false; };
