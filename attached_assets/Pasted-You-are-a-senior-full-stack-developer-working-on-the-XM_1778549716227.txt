Issue 3 — Shop Orders: Customer Cannot Place an Order (Firebase undefined Field Error)
What is happening:
When a customer attempts to place an order from a shop listing, the order submission fails with the following Firebase error:
Function addDoc() called with invalid data. Unsupported field value: undefined
(found in field offeredPrice in document shopOrders/Fo8NfJzH2SxznTZ3AEtW)
This means the offeredPrice field is being passed as undefined to Firestore's addDoc() call, which Firestore strictly rejects. Orders cannot be placed by any customer on any shop listing.
Where to look:

artifacts/xmum-market/src/pages/OrderFormPage.tsx — where the order object is assembled and createOrder() is called
artifacts/xmum-market/src/lib/shops.ts — the createOrder() function that calls addDoc()

What needs to change:

Before calling addDoc(), every field in the order object must be checked for undefined. Any field that is optional and currently undefined must be replaced with null or an appropriate default value (empty string "" for text fields, 0 for numeric fields) before being passed to Firestore
Specifically for offeredPrice: this field is only relevant when the listing's pricingModel is "negotiable". For all other pricing models, offeredPrice should be explicitly set to null rather than left as undefined
Apply the same undefined safety check to all other optional fields in the order payload to prevent this class of error from appearing on any other field in the future
