CRITICAL PRODUCTION BUG — FIX IMMEDIATELY:

FILE: artifacts/xmum-market/src/pages/ProfilePage.tsx

THE BUG:
Inside the onSnapshot callback in the listings useEffect, the raw Firestore document data is mapped like this:

  const data = snap.docs.map((d) => ({ id: d.id, ...d.data() } as Listing));

This leaves createdAt as a raw Firestore Timestamp object. When the expiry check runs:

  now - l.createdAt >= LISTING_EXPIRY_MS

JavaScript coerces the Timestamp to its .seconds value (NOT milliseconds), making every listing appear 1000x older than it really is. This causes ALL listings to appear expired and get immediately deleted when any user opens their profile page.

THE FIX:
Change ONLY the data mapping line inside the onSnapshot callback. Replace:

  const data = snap.docs.map((d) => ({ id: d.id, ...d.data() } as Listing));

With:

  const data = snap.docs.map((d) => {
    const raw = d.data();
    const createdAt = raw.createdAt && typeof raw.createdAt.toMillis === "function"
      ? raw.createdAt.toMillis()
      : typeof raw.createdAt === "number"
      ? raw.createdAt
      : Date.now();
    return { id: d.id, ...raw, createdAt } as Listing;
  });

Do NOT change anything else. Do NOT touch the expiry logic, the initialRun flag, the deleteListing calls, the imports, or any other part of the file.
