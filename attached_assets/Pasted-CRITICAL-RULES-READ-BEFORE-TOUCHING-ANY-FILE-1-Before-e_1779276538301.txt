PART 7 — Fix: Blacklisted users can still post, message, and take all actions

THE BUG:
The isBlacklisted flag is set by admins in the admin panel and stored on the user profile
in Firestore. But nothing in the market app checks it. Banned users continue posting,
messaging, and using all features normally.

IMPORTANT BEFORE YOU START:
Read the following files completely before touching any of them:
- artifacts/xmum-market/src/contexts/AuthContext.tsx
- artifacts/xmum-market/src/pages/PostPage.tsx
- artifacts/xmum-market/src/pages/MessagesPage.tsx

The strategy is: check isBlacklisted from userProfile (already available via AuthContext)
at the point of action, not at page load. We do NOT redirect banned users away from pages
or show a full-screen block — we only prevent the specific actions (posting, sending messages)
and show a clear inline error. This is the safest approach that touches the least code.
