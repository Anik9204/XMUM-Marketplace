TASK: Make the user's own listings on ProfilePage update in real-time — so if they mark a listing sold, delete it, or an admin archives it, the profile listing list reflects this without a page refresh.

FILE: artifacts/xmum-market/src/pages/ProfilePage.tsx

First read the file fully. Identify the useEffect that fetches the user's listings (it calls getUserListings or equivalent getDocs-based fetch with the user's uid).

THE FIX:
Replace that one-time getDocs fetch for the user's own listings with an onSnapshot listener.

Add these imports if not already present:
  import { collection, query, where, orderBy, onSnapshot } from "firebase/firestore";
  import { db } from "@/lib/firebase";
  import { Listing } from "@/lib/types";

Replace the useEffect that loads the user's listings with:

  useEffect(() => {
    if (!user?.uid) return;
    const q = query(
      collection(db, "listings"),
      where("userId", "==", user.uid),
      orderBy("createdAt", "desc")
    );
    const unsub = onSnapshot(q, (snap) => {
      const docs = snap.docs.map((d) => ({ id: d.id, ...d.data() } as Listing));
      setUserListings(docs);
    }, () => {});
    return () => unsub();
  }, [user?.uid]);
