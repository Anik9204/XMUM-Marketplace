STEP 1 — Update types.ts

File: artifacts/xmum-market/src/lib/types.ts

In the ShopListing interface, add one field alongside the existing isBoosted/boostedUntil/isUrgent/urgentUntil fields added in the previous credit system work:

This field holds the expiry timestamp of the active boost. Higher = sorts higher.

STEP 3 — Update getAllShopListings sort in shops.ts

File: artifacts/xmum-market/src/lib/shops.ts

Find the getAllShopListings function. It currently ends with:

  return listings
    .filter((l) => shopStatuses[l.shopId] !== false)
    .slice(0, limitCount);

Change ONLY the final sort+filter chain to:

  const now = Date.now();
  return listings
    .filter((l) => shopStatuses[l.shopId] !== false)
    .sort((a, b) => {
      const aScore = (a.boostScore && a.boostScore > now) ? a.boostScore : 0;
      const bScore = (b.boostScore && b.boostScore > now) ? b.boostScore : 0;
      if (bScore !== aScore) return bScore - aScore;   // boosted first
      return b.createdAt - a.createdAt;                // then by recency
    })
    .slice(0, limitCount);
