## FIX 2 — Auto-delete old banner/logo from Storage when a new one is uploaded

**File:** `artifacts/xmum-market/src/components/ShopManagementPanel.tsx`

The `onBannerUpload` and `onLogoUpload` handlers (inside the main `ShopManagementPanel` return, around line 1132) currently just upload and update Firestore. They need to delete the OLD file from Storage first.

`ref` and `deleteObject` are already imported from `firebase/storage` at the top of the file. `storage` is already imported from `@/lib/firebase`. A `storagePathFromUrl` function already exists in the file (inside `EditListingForm`). Do NOT move or duplicate that function — instead add a small inline helper at the top of the `onBannerUpload` and `onLogoUpload` handlers.

Find:
```
onBannerUpload={async (file) => {
  const url = await uploadShopBanner(shopId, file);
  await updateShop(shopId, { bannerUrl: url });
  updateShopState({ bannerUrl: url });
}}
```
Replace with:
```
onBannerUpload={async (file) => {
  const oldUrl = shop.bannerUrl;
  const url = await uploadShopBanner(shopId, file);
  await updateShop(shopId, { bannerUrl: url });
  updateShopState({ bannerUrl: url });
  if (oldUrl) {
    try {
      const oldPath = decodeURIComponent(oldUrl.split("/o/")[1]?.split("?")[0] ?? "");
      if (oldPath) await deleteObject(ref(storage, oldPath)).catch(() => {});
    } catch {}
  }
}}
```

Find:
```
onLogoUpload={async (file) => {

  updateShopState({ logoUrl: url });
}}
```
Replace with:
```
onLogoUpload={async (file) => {
  const oldUrl = shop.logoUrl;
  const url = await uploadShopLogo(shopId, file);
  await updateShop(shopId, { logoUrl: url });
  updateShopState({ logoUrl: url });
  if (oldUrl) {

    } catch {}
  }
```
