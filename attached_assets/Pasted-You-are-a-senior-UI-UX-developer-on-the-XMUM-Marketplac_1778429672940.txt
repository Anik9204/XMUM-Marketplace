BUG 1 — BUMP LISTING COOLDOWN NOT ENFORCED SERVER-SIDE
═══════════════════════════════════════════════
PROBLEM: bumpListing in listings.ts reads lastBumpedAt from Firestore
BEFORE updating. This is correct. However, there is a race condition:
if two devices bump the same listing simultaneously, both read
lastBumpedAt before either writes, both pass the cooldown check, and
both write — resulting in two bumps within seconds. Also, the 24h
cooldown check uses LISTING_EXPIRY_MS constant instead of a dedicated
BUMP_COOLDOWN_MS.

FIX: In artifacts/xmum-market/src/lib/listings.ts:

  1. Add at the top (near LISTING_EXPIRY_MS):
       export const BUMP_COOLDOWN_MS = 24 * 60 * 60 * 1000; // 24 hours

  2. In bumpListing function, verify it uses BUMP_COOLDOWN_MS not any
     other constant. If it uses any other value, replace with
     BUMP_COOLDOWN_MS.

  3. The function should return { success: boolean; nextBumpAt: number }
     Check that it does. If it only returns void, update it:

     export async function bumpListing(id: string):
       Promise<{ success: boolean; nextBumpAt: number }> {
       try {
         const ref = doc(db, "listings", id);
         const snap = await getDoc(ref);
         if (!snap.exists()) return { success: false, nextBumpAt: 0 };
         const data = snap.data();
         const lastBumpedAt: number = data.lastBumpedAt ?? 0;
         const now = Date.now();
         if (now - lastBumpedAt < BUMP_COOLDOWN_MS) {
           return { success: false, nextBumpAt: lastBumpedAt + BUMP_COOLDOWN_MS };
         }
         await updateDoc(ref, { lastBumpedAt: now, sortKey: now });
         return { success: true, nextBumpAt: now + BUMP_COOLDOWN_MS };
       } catch (err) {
         console.error("[bumpListing] failed:", err);
         return { success: false, nextBumpAt: 0 };
       }
     }

  4. In ProfilePage.tsx, import BUMP_COOLDOWN_MS from "@/lib/listings"
     and use it for the cooldown display:
       const onCooldown = !!l.lastBumpedAt &&
         Date.now() - l.lastBumpedAt < BUMP_COOLDOWN_MS;
