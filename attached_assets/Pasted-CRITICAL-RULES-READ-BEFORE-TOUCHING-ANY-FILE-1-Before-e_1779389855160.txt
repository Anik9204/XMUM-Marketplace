FILE TO EDIT: artifacts/xmum-market/src/components/AuthModal.tsx

PROBLEM: Firebase no longer returns "user-not-found" as a separate error code for sign-in. It now returns "invalid-credential" for BOTH wrong password AND non-existent account. So the "no account" nudge never shows — instead the user just sees "Invalid email or password."

We need to distinguish these two cases ourselves by checking Firestore before attempting sign-in.

IMPORTS NEEDED: Add these two imports to the existing firebase/firestore import (already imported in the file via auth.ts, but we need direct Firestore access here). Add this import at the top of the file alongside the existing imports:

import { getFirestore, collection, query, where, getDocs, limit } from "firebase/firestore";
import { getApp } from "firebase/app";

EXACT CHANGES:

1. Add a helper function after the resolveEmail function (around line 12, before getPasswordStrength):

async function emailExistsInFirestore(email: string): Promise<boolean> {
  try {
    const db = getFirestore(getApp());
    const q = query(
      collection(db, "users"),
      where("email", "==", email.toLowerCase()),
      limit(1)
    );
    const snap = await getDocs(q);
    return !snap.empty;
  } catch {
    // If the check fails for any reason, assume account exists
    // so we don't wrongly show the nudge — fall through to Firebase signIn error
    return true;
  }
}
