FIX 1 — shopListingHasActiveReport queries the forbidden `reports` collection
File: artifacts/xmum-market/src/lib/reportHold.ts

The current function queries the `reports` collection which regular users cannot read (403). The fix is to read the `isReportHeld` field directly from the shopListing document — the same pattern used by `listingHasActiveReport`.

Find the entire shopListingHasActiveReport function:
  export async function shopListingHasActiveReport(listingId: string): Promise<boolean> {
    const q = query(
      collection(db, "reports"),
      where("listingId", "==", listingId),
      where("status", "in", ["pending", "reviewed"]),
      limit(1)
    );
    const snap = await getDocs(q);
    return !snap.empty;
  }

Replace the entire function body (keep the function signature) with:
  export async function shopListingHasActiveReport(listingId: string): Promise<boolean> {
    try {
      const snap = await getDoc(doc(db, "shopListings", listingId));
      if (!snap.exists()) return false;
      return snap.data().isReportHeld === true;
    } catch {
      return false;
    }
  }

Check that `getDoc` and `doc` are already imported at the top of reportHold.ts. They should be — `listingHasActiveReport` uses them. If they are not, add them to the existing firebase/firestore import line.

You can now remove the imports that are no longer used by this file: `collection`, `query`, `where`, `getDocs` (if they are ONLY used by the old shopListingHasActiveReport function and nothing else in the file). Check carefully — only remove an import if nothing else in the file uses it.

Change it to also set an error state so the admin sees a message instead of a blank table. First, check if there is already an error state in this component. If not, add one near the other useState declarations:
