### 🐛 Bug 2 — Reports require a manual page refresh (no real-time updates)
**Root cause:** `ReportsPage.tsx` uses `getDocs()` (one-time fetch) inside `useEffect` that runs only once on mount. There is no Firestore real-time listener (`onSnapshot`).

**Prompt for Replit:**
> In `artifacts/xmum-admin/src/pages/ReportsPage.tsx`, replace the one-time `getDocs` call with a Firestore real-time listener using `onSnapshot`. Import `onSnapshot` from `"firebase/firestore"`. Inside `useEffect`, call:
> ```ts
> const q = query(collection(db, "reports"), orderBy("createdAt", "desc"));
> const unsub = onSnapshot(q, (snap) => {
>   setReports(snap.docs.map(d => ({ id: d.id, ...d.data() } as ListingReport)));
>   setLoading(false);
> }, (err) => {
>   console.error("[ReportsPage] onSnapshot error:", err);
>   setLoading(false);
> });
> return () => unsub();
> ```
> Remove the old `load()` function and the manual `setLoading(true)` call that was used for it. This makes new reports appear in real time without any manual refresh.

### 🐛 Bug 3 — Deleting a report does NOT delete the listing from the database or the user's view
**Root cause:** `deleteReport()` in `ReportsPage.tsx` only calls `deleteDoc(doc(db, "reports", id))`, which removes the **report document** — not the actual **listing** that was reported. The `deleteDoc` for the listing in the `listings` collection is never called, and no notification is sent to the user.

**Prompt for Replit:**
> In `artifacts/xmum-admin/src/pages/ReportsPage.tsx`, fix the `deleteReport` function. It currently only deletes the report document, but it needs to also delete the associated listing from Firestore and optionally notify the listing owner. Replace the `deleteReport` function with this logic:
> ```ts
> async function handleActionAndDelete(report: ListingReport) {
>   if (!isAdmin) return;
>   const confirmed = window.confirm(
>     `This will permanently delete the listing "${report.listingTitle}" and its report. Continue?`
>   );
>   if (!confirmed) return;
>   try {
>     // Delete the listing from the listings collection
>     await deleteDoc(doc(db, "listings", report.listingId));
>     // Delete the report document itself
>     await deleteDoc(doc(db, "reports", report.id));
>     // Optionally write a notification to the listing owner
>     await addDoc(collection(db, `users/${report.listingUserId}/notifications`), {
>       type: "listing_removed",
>       message: `Your listing "${report.listingTitle}" was removed by an admin due to a policy violation.`,
>       createdAt: Date.now(),
>       read: false,
>     });
>     setReports(prev => prev.filter(r => r.id !== report.id));
>   } catch (e) {
>     console.error("[ReportsPage] delete failed:", e);
>     alert("Failed to delete listing/report. Check Firestore permissions.");
>   }
> }
> ```
> Also import `addDoc` from `"firebase/firestore"` if not already imported. Update the Delete button's `onClick` to call `handleActionAndDelete(report)` instead of `deleteReport(report.id)`.
